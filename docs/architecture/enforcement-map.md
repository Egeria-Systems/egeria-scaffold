# Architecture Enforcement Map

This document is the canonical owner for mapping invariants to actual or planned gates. “Planned” means the gate does not exist yet; documentation must not describe it as passing. Phase ownership follows the [program roadmap](../roadmaps/program-roadmap.md).

The exact P0.2 matrix, command meanings, runtime distinctions, deployment evidence, and claim limits are recorded in the [Next.js and Cloudflare compatibility record](../compatibility/nextjs-cloudflare.md). Local workflow structure proves only the repository contract; the recorded successful GitHub Actions run and non-production Worker evidence establish the separate external deployment result.

P1 Task 6 deterministic in-memory rendering is guarded by `packages/builder-core/tests/render-skeleton.test.mjs` and the exact source and template allowlists in `tests/package-boundaries/private-packages.test.mjs`. These gates prove returned bytes, catalog/file boundaries, copy placement, and ownership agreement only. They do not prove a fresh generated install, lockfile, build, workerd runtime, deployment, visual result, translation quality, accessibility conformance, human usability, security audit, or production safety.

P1 new-directory generation is guarded by `packages/builder-core/tests/generate-project.test.mjs`. Its injected-verifier tests prove exclusive source writes, exact lockfile inventory, pre-state and post-state agreement, state-last ordering, exact installed surfaces, destination refusal, identity-bounded cleanup, and stable failure behavior. They do not prove that pnpm, a public-registry install, Next, or OpenNext actually ran; that evidence belongs to the explicit live generated-project integration gate.

## Updating enforcement ownership

When a planned gate is implemented, update this table in the same focused change as the executable gate and its test. Record the exact command and result in implementation evidence. Passing a document-structure contract proves only structure and ownership; it does not prove prose semantics or a later runtime gate.

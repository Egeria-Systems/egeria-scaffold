# Builder core boundary

The [current environment generation](../../docs/architecture/capability-model.md#current-environment-generation) owns the schema-2 public source candidate, exact installed tuples, current lifecycle and pending acceptance. [ADR-0020](../../docs/adr/0020-application-environments.md#public-environment-generation-activation) owns the precise retirement of old executable generation and edges. Preserve its operation-specific safeguards, historical evidence and separate runtime/certification/publication gates. Routine stream approval uses only the [scoped governance exception](../../docs/governance/review-and-contribution.md#lean-application-environments-delivery-exception).

Read the repository [`AGENTS.md`](../../AGENTS.md), the canonical [package ownership](../../docs/architecture/package-ownership.md), and the [review and contribution protocol](../../docs/governance/review-and-contribution.md) before editing this surface.

`packages/builder-core` privately owns the current schema-2 contracts, fourteen-capability admission catalog, actual installed tuples, deterministic resolution/rendering, state/inference/diagnostics, hybrid ownership, Git preflight and operation-specific current transactions. The canonical current generation boundary defines supported recipes, optional lifecycle, incoming app edges and stable retirement refusals. Historical controls, templates, locks and receipts stay preserved; no executable historical snapshot, generic lifecycle executor or automatic migration is introduced.

The public parser and renderer share the current environment contract. Default app selects foundation plus routing; optional server capabilities select their declared dependencies independently. Worker verification follows installed foundation, and persistence adds its separate binding checks. Keep Effect out of builder-core and the CLI.

# `@egeria-systems/builder-core`

Private ownership boundary for future Egeria Systems builder internals.

P0.3 materializes only an empty ESM module. Project/state schemas, capability resolution, inference, planning, migrations, repository transformation, verification, and recovery begin only in their approved later stages. A separate project-schema package is intentionally absent.

The canonical API and lifecycle owner is [package ownership](../../docs/architecture/package-ownership.md).

# `@egeria-systems/cli`

Private command-surface boundary for the Egeria Systems builder.

P0.3 materializes only an empty ESM module. It has no executable command, `bin` entry, dependency, profile behavior, schema, generator, migration, or state mutation. Later command behavior requires its own approved roadmap increment.

The canonical API and lifecycle owner is [package ownership](../../docs/architecture/package-ownership.md).
